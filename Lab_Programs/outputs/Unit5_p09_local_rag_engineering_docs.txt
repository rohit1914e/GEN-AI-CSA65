**What is the TLB?**
The Translation Lookaside Buffer (TLB) is a hardware component that caches recent page-table entries. It stores information about how virtual addresses are mapped to physical addresses so that the CPU does not need to constantly look up this data in main memory.

**Why is it used?**
It is used to avoid the extra read time associated with accessing the page table. The context explains that a TLB hit allows the system to use the cached entry directly, whereas a miss requires two memory reads (one for the TLB and one for the actual data). This significantly improves the effective access time of memory operations.
